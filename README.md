# Todos Local Storage 📋

โปรเจกต์ To-Do List ใช้ฝึกทักษะการใช้ `Web Storage API` โดยเก็บรายการต่างๆ ด้วย `localStorage` ไว้ในเบราว์เซอร์ของผู้ใช้ ทำให้เมื่อเปิดหน้าเว็บใหม่ รายการที่จดไว้ยังอยู่เหมือนเดิม

🔗 [Live Demo](https://2boycats.github.io/Todos-Local-Storage/)

## ✨ Features
- เพิ่มรายการได้ไม่จำกัดจำนวน
- ลบรายการที่ต้องการได้ทีละรายการ
- รายการที่เพิ่มไว้จะไม่หายไปเมื่อรีเฟรชหรือเปิดหน้าเว็บใหม่

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- Web Storage API (ของเบราว์เซอร์)

## 🚀 วิธีรันโปรเจกต์
1. เปิดโฟลเดอร์โปรเจกต์ด้วย VS Code
2. ใช้ Live Server เปิดไฟล์ `index.html`

## 🔄 การทำงานของระบบ
1. ดึงข้อมูลจาก `localStorage` ด้วยคีย์ `todos` แล้วแปลงจากข้อความ JSON เป็นอาร์เรย์ด้วย `JSON.parse` หากไม่มีข้อมูลให้เริ่มจากอาร์เรย์ว่าง
2. นำรายการในอาร์เรย์มาวนลูปสร้างเป็นชื่อรายการพร้อมปุ่มลบของแต่ละรายการ แล้วแสดงบนหน้าเว็บ
3. เมื่อผู้ใช้กดเพิ่มรายการ จะนำค่าที่ได้มาตัดช่องว่างหัวท้ายด้วย `.trim()` แล้ว `push` เข้าไปในอาร์เรย์
4. บันทึกอาร์เรย์ลง `localStorage` โดยแปลงเป็นข้อความด้วย `JSON.stringify` ก่อน จากนั้นแสดงรายการบนหน้าเว็บใหม่อีกครั้ง
5. เมื่อกดปุ่มลบ จะลบรายการนั้นออกจากอาร์เรย์ด้วย `splice` แล้วบันทึกและแสดงผลใหม่เช่นเดียวกัน

## 📝 หมายเหตุ
- ข้อมูลถูกเก็บในเบราว์เซอร์ของแต่ละเครื่อง จึงไม่แชร์ข้ามเครื่องหรือข้ามเบราว์เซอร์
- ถ้าผู้ใช้ล้างข้อมูลเว็บไซต์ (Clear site data) รายการจะหายไป

## 📚 สิ่งที่ได้เรียนรู้
- การใช้ `localStorage` ด้วย `getItem` และ `setItem` เพื่อเก็บข้อมูลถาวรในเบราว์เซอร์
- การแปลงข้อมูลไปมาระหว่างอาร์เรย์กับข้อความด้วย `JSON.stringify` และ `JSON.parse`
- การสร้างและลบองค์ประกอบ DOM ด้วย `createElement`, `appendChild` และการ render ใหม่จากข้อมูล
- การดักเหตุการณ์ `submit` ของฟอร์มและใช้ `preventDefault()`

## 🔮 แผนพัฒนาต่อ
- แก้ไขชื่อรายการที่เพิ่มไปแล้วได้
- ลากเพื่อสลับตำแหน่งระหว่างรายการ (drag and drop)
- เพิ่มปุ่มติ๊กทำเสร็จแล้ว (mark as done)
